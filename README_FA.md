# HARISGARD 4.0 — Android project

این پروژه شامل نسخه وب هریس‌گرد، پوسته Android WebView، آیکون برنامه و اعلان روزانه بومی اندروید است.

## ساخت APK از GitHub (پیشنهادی)
1. محتویات پوشه `HARISGARD_Android_Project` را در ریشه یک مخزن جدید GitHub بارگذاری کنید (فایل `.github/workflows/build-apk.yml` باید در ریشه مخزن باشد).
2. از تب Actions، گردش‌کار `Build HARISGARD APK` را اجرا کنید (یا یک commit بزنید).
3. پس از پایان موفق، از بخش Artifacts فایل `HARISGARD-debug-APK` را دریافت کنید. برای ساخت نسخه release امضاشده، Secrets با نام‌های `ANDROID_KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS` و `KEY_PASSWORD` را در تنظیمات مخزن وارد کنید؛ فایل keystore باید همان کلید نسخه قبلی برنامه باشد.

## ساخت با Termux
ساخت مستقیم روی گوشی به Android SDK و Gradle و فضای کافی نیاز دارد و روی همه نسخه‌های Termux بی‌دردسر نیست. اگر SDK و Gradle 8.7 و JDK 17 نصب و تنظیم شده‌اند:

```bash
cd HARISGARD_Android_Project
gradle assembleDebug
```

خروجی: `app/build/outputs/apk/debug/app-debug.apk`

## اعلان روزانه
- اعلان با انتخاب کاربر فعال می‌شود؛ مجوز Android 13+ در لحظه فعال‌سازی درخواست می‌شود.
- زمان‌بندی با WorkManager و حدود هر ۲۴ ساعت است؛ اندروید ممکن است برای صرفه‌جویی باتری زمان دقیق را کمی جابه‌جا کند.
- برای توقف، دکمه «خاموش کردن اعلان» داخل برنامه را بزنید.
- اعلان‌ها کاملاً محلی هستند و سرور/API لازم ندارند.

## پایگاه خبری
نمایش داخل برنامه با iframe تلاش می‌شود. اگر وب‌سایت از نمایش در iframe جلوگیری کند، دکمه بازکردن در مرورگر گوشی موجود است؛ APK این محدودیت امنیتی سایت را دور نمی‌زند.

## نسخه و شناسه
- نام: هریس‌گرد
- applicationId: `com.harisgard.app`
- versionName: `4.0.0`
- minSdk: 23
- targetSdk: 35

این ZIP پروژه منبع است، نه APK امضاشده انتشار. برای انتشار یا به‌روزرسانی در مایکت، APK باید با کلید امضای نسخه قبلی همان برنامه امضا شود. اگر keystore قبلی را نداری، این APK را نمی‌توان به‌عنوان به‌روزرسانی روی همان برنامه منتشر کرد. همچنین `applicationId` باید دقیقاً با شناسه بسته نسخه فعلی مایکت یکسان باشد. کلید امضا را در مخزن عمومی یا داخل ZIP قرار نده؛ فقط در GitHub Secrets خصوصی نگه دار.


**توجه:** APK دیباگ فقط برای نصب و آزمایش است؛ برای مایکت باید خروجی release امضاشده با کلید اصلی برنامه استفاده شود.
